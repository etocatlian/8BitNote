8BitNote website
================

Put these files on any web host that serves https, for example GitHub Pages:

1. Create a GitHub repository (for example "8bitnote") and upload every file in this folder.
2. In the repository's Settings > Pages, choose "Deploy from a branch", branch "main", and save.
3. After a minute the app is at https://YOUR-NAME.github.io/8bitnote/

Once it is online:
- Chrome and Edge show an "Install" button in the address bar; Safari on iPhone/iPad: Share > Add to Home Screen;
  Safari on Mac: File > Add to Dock.
- After the first visit it also opens without an internet connection.

To update the app later, replace index.html with the new version.

8BitNote isn't affiliated with or endorsed by the makers of the computers and consoles it imitates.
Names and trademarks belong to their owners. Before publishing, consider hiding the maker badges
on the keyboard pictures (Vintage menu > Maker badge > Hidden) or removing them from the pictures.

8Bit's voice uses the eSpeak speech synthesizer through meSpeak.js by Norbert Landsteiner, released under the GNU General Public License. Its code is included inside index.html in compressed form; the source is available from masswerk.at/mespeak and github.com/espeak-ng.
